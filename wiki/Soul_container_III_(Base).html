The Soul container III (Base) is a workbench introduced with the Better Save Soul DLC, that may be built in the Souls room after you unlock the Updated equipment technology. Soul container III (Base) has no use on its own other than being a prerequisite before using Soul container III. The Soul container III allows you to store up to 4 souls for later usage. Unlike the previous tiers of soul containers, souls stored at Soul container III no longer decay.

To use one of these containers first, you have to build a frame first, Soul container III (Base), then fill it up by finishing the build with extra materials. There are only 3 spots in the Souls room where this container can be built.

Note: When a soul stays in the container for too long, it will eventually die and leave a Sin Shard behind. No drop in soul condition was observed in soul container III after 2 days , while in other containers souls decayed. Either rate of decay slow or absent.
